# 광평중학교 음악중점반 홍보영상 2편 (2분 20초 · 16:9)

"처음엔 악기 이름도 몰랐던" 신입생이 3년 뒤 정기연주회 무대에 서기까지의 이야기를 담았습니다. 2025–2026 학교 행사 사진 51장, 학교 음악 공간 사진 14장, 오리지널 BGM으로 만든 2027학년도 신입생 모집용 영상입니다.

- `gwangpyeong-music-promo-v2.mp4`: 완성 영상 (1080p 30fps, H.264 + AAC)
- `gwangpyeong-music-promo-v2.html`: 브라우저에서 바로 재생되는 단일 파일 (폰트·음원·사진 내장, 약 13MB)
- `bgm.mp3`: 오리지널 BGM (120 BPM, 70마디 = 2분 20초). 샘플 없이 코드로 합성한 오케스트라 팝 편곡(피아노·현·금관·합창·글로켄슈필·어쿠스틱 드럼)이라 저작권 걱정이 없습니다. 정기연주회부터는 A장조로 전조하고, 마지막은 첫 장면의 조율음 A로 끝납니다.
- 사진 원본과 출처: `../photos/`, `../photos/SOURCES.md`

## 날짜·인원이 바뀌면

`config.js`만 고치면 됩니다. 입학설명회, 원서 접수 기간·시간, 원서 교부, 접수처, 문의 전화, 주소가 모두 들어 있고, 모집 인원은 빈칸이면 화면에서 숨겨집니다.

```bash
cd v2
node build.mjs          # 웹용 HTML
node build.mjs --hi     # 영상 렌더용 HTML
node video.mjs          # MP4 (약 40분)
node video.mjs 120 140  # 엔딩 구간만 미리보기 → preview.mp4
```

처음 한 번은 `npm i --no-save ffmpeg-static@5`가 필요합니다. BGM을 바꾸려면 `node music.mjs`를 먼저 실행하세요 (합성에 약 1분).
