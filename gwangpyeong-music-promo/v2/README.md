# 광평중학교 음악중점반 홍보영상 2편 (2분 · 16:9)

"처음엔 악기 이름도 몰랐던" 신입생이 3년 뒤 정기연주회 무대에 서기까지의 이야기를 담았습니다. 2025–2026 학교 행사 사진 51장과 오리지널 BGM으로 만든 2027학년도 신입생 모집용 영상입니다.

- `gwangpyeong-music-promo-v2.mp4`: 완성 영상 (1080p 30fps, H.264 + AAC)
- `gwangpyeong-music-promo-v2.html`: 브라우저에서 바로 재생되는 단일 파일 (폰트·음원·사진 내장, 약 13MB)
- `bgm.mp3`: 오리지널 BGM (120 BPM, 60마디 = 2분). 샘플 없이 코드로 합성한 곡이라 저작권 걱정이 없습니다.
- 사진 원본과 출처: `../photos/`, `../photos/SOURCES.md`

## 날짜·인원이 정해지면

`config.js`만 고치면 됩니다. 입학설명회 날짜는 지금 `○○`로 비워 두었고, 모집 인원은 빈칸이면 화면에서 숨겨집니다.

```bash
cd v2
node build.mjs          # 웹용 HTML
node build.mjs --hi     # 영상 렌더용 HTML
node video.mjs          # MP4 (약 30분)
node video.mjs 108 120  # 엔딩 구간만 미리보기 → preview.mp4
```

처음 한 번은 `npm i --no-save ffmpeg-static@5`가 필요합니다. BGM을 바꾸려면 `node music.mjs`를 먼저 실행하세요.

## 정기연주회 사진 넣기

제4회 정기연주회 원본(9–16MB)은 드라이브 커넥터 용량 제한 때문에 아직 받지 못했습니다. 작게 줄인 사진을 `../photos/concert25-01.jpg` ~ `concert25-05.jpg`로 넣고 다시 빌드하면, 1:32부터 나오는 클라이맥스 장면에 자동으로 들어갑니다. 그 전까지는 경북교육 웹진에 실린 정기연주회 사진 4장이 흐린 배경 + 액자 카드로 나옵니다. 원본을 넣으면 원본이 먼저 쓰입니다(concert25-01~07).
